Home/HBO Max

Cross-platform UI systems for streaming experiences.

I developed production-quality UI for HBO Max, from earlier React Native work across web, iOS, and Android to more recent web-team work focused on browser experiences. This public case study is intentionally generalized to protect confidential product, implementation, and performance details.

Confidentiality Note

This case study does not include proprietary screenshots, unreleased product details, internal metrics, architecture diagrams, or implementation specifics. The writing focuses on my public-safe design-engineering approach.

What I Built

I contributed to HBO Max UI systems, translating design intent into reusable frontend patterns across changing platform needs. Earlier work required considering React Native experiences across web, iOS, and Android; more recent work has focused on web browser behavior, accessibility, performance, and production reliability.

Reusable Components

Built and refined component patterns that could scale across multiple product surfaces while preserving interaction consistency.

Design Partnership

Worked closely with designers to evaluate feasibility, prototype interaction details, and ship polished UI states.

Production Quality

Resolved UX-impacting bugs and implementation gaps that affected interface stability, accessibility, and user trust.

Interaction Challenges

Streaming interfaces need to feel fluid across device types, navigation patterns, content density, accessibility needs, and changing product requirements. My work focused on implementation details that users may not consciously notice but feel immediately when they are wrong.

  • Accounting for web, iOS, and Android needs during earlier React Native work, then focusing more deeply on browser behavior as part of the web team.
  • Supporting accessible focus, navigation, and readable UI states.
  • Preserving visual polish while working within shared component APIs.
  • Debugging production issues where technical defects surfaced as UX friction.

Engineering Decisions

I treated component implementation as a design tool: APIs needed to be clear enough for engineers to reuse, flexible enough for designers to evolve, and strict enough to protect consistency while keeping production standards intact.

As the company has been actively pushing AI-supported engineering workflows, I also use AI tools as part of my development process for prototyping, debugging, implementation exploration, and faster iteration. I frame this as engineering workflow experience, not as a claim that this case study represents an AI product.

Impact

The work supported consumer-scale streaming experiences and helped teams deliver more consistent UI across platforms. Because the exact product and business metrics are confidential, this section frames impact qualitatively: stronger design-engineering alignment, more reusable frontend patterns, and higher attention to interaction quality in production.
