MAY · MOTION AND CHARACTER STATES

May reacts to what the system is doing.

Six states carry the whole product: idle, waiting, working, success, failure and first load. Every animation on this page is live — no video, no GIF. They move only transform and opacity, loop under two seconds unless they are ambient, and stop entirely under prefers-reduced-motion.

02 · Character states

Five loops, one rule each

All ambient loops ≥ 1.1s so they never nag

Idle · breathing

3.6s · translateY 4px + scale 1.5%

Empty dashboard, waiting for the user. The slowest loop in the system — it should read as presence, not activity.

Thinking · waiting on the agent

4s sway ±2.2° · the question mark is part of the pose artwork

Brief generation, planning, analysis. The sway is slower than the build loop so the two states never feel alike.

Building · working

1.1s bounce ±0.6° — the fastest loop

A run is executing. Faster cadence signals machine work rather than deliberation.

✦ ✦

Success · published

1.6s hop, spring easing · sparkles offset 250ms

Beta accepted or version published. In production this plays twice and settles into idle — celebration should end.

Resting · error or failed build

5s breathe, tilted −7°, saturation 75%

Something broke. May sits down rather than looking alarmed: the interface already carries the error, so the character should lower the temperature, not raise it.

No character

04 · Timing

Every duration in the system

Token Value Easing Used by
--dur-quick 180ms ease-calm State swaps, button feedback, cross-fades
--dur-calm 900ms ease-calm Splash reveal, first paint of a panel
--loop-work 1.1s ease-calm Building — the fastest loop
Success hop 1.6s ease-spring Published, beta accepted
Dot wave 1.4s ease-calm Short waits, 140ms stagger per dot
Track slide 1.8s ease-calm Indeterminate progress
--loop-breathe 3.6s ease-calm Idle presence
--loop-think 4s ease-calm Waiting on the agent
Resting breathe 5s ease-calm Error and failed build — the slowest loop

Four rules

One moving thing per screen. The character or the progress element, never both competing.

Slower means calmer. Error is the slowest loop in the system; building is the fastest.

Transform and opacity only. No width, top, or filter animation in loops — they cost layout and paint.

Motion is never the status. A spinner does not say what stage a run is in; text does.

Accessibility

Under prefers-reduced-motion: reduce every loop on this page stops, the indeterminate track becomes a full static bar, and the floating marks hold at 60% opacity. Nothing depends on movement to be understood: each state also carries a label, a heading and, in the product, its own text.

Announce state changes with aria-live="polite" on the status line, not on the character — the character is decorative and ships with an empty alt.

05 · Implementation

Copy this into the product

Tokens and loops

:root {
  --dur-quick: 180ms;
  --dur-calm: 900ms;
  --loop-breathe: 3.6s;
  --loop-think: 4s;
  --loop-work: 1.1s;
  --ease-calm: cubic-bezier(.4, 0, .2, 1);
  --ease-spring: cubic-bezier(.34, 1.4, .5, 1);
}

@keyframes may-breathe {
  0%, 100% { transform: translateY(0) scale(1); }
  50%      { transform: translateY(-4px) scale(1.015); }
}
@keyframes may-think {
  0%, 100% { transform: rotate(-2.2deg) translateY(0); }
  50%      { transform: rotate(2.2deg) translateY(-3px); }
}
@keyframes may-rest {
  0%, 100% { transform: rotate(-7deg) translateY(0) scale(1); }
  50%      { transform: rotate(-7deg) translateY(-2px) scale(1.01); }
}

Binding a state

<figure class="may-state" data-state="thinking">
  <img src="may-character-thinking.png" alt="" />
</figure>

.may-state img { transform-origin: 50% 100%; }
[data-state="idle"]    img { animation: may-breathe var(--loop-breathe)
                             var(--ease-calm) infinite; }
[data-state="thinking"] img { animation: may-think var(--loop-think)
                             var(--ease-calm) infinite; }
[data-state="failed"]   img { animation: may-rest 5s var(--ease-calm) infinite;
                              filter: saturate(.75); }

@media (prefers-reduced-motion: reduce) {
  .may-state img { animation: none; }
}

The character alt stays empty — it repeats what the status text already says. Put aria-live="polite" on the status line instead so a screen reader hears the state change once.
